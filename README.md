# Kieshun Dixon | Personal Web Page

A personal web page built with HTML and CSS for my Introduction to Information Technology class. It introduces who I am, what I'm studying, and my goals in cybersecurity.

## About

I'm a full-time Information Technology student with a background in customer service and technical support. This page covers my experience, interests, and the steps I'm taking toward a career in cybersecurity.

## Features

- Semantic HTML with a skip link and labeled navigation for accessibility
- Responsive layout that adapts to phones and desktops using media queries
- Flexbox layout for the Personal and Professional interests section
- CSS Grid layout for the navigation links
- Google Fonts (Montserrat and Open Sans)

## Files

- `index.html`: page content
- `styles.css`: page styling
- `kieshun.jpg`: profile photo
